# Masud Learning Campus

Upload index.html, style.css, app.js, three.module.js, and .nojekyll to the root of your GitHub Pages repository.

In Settings > Pages, select Deploy from a branch, main, / (root), then Save.

Edit content in app.js and styling in style.css.

Three.js r170 is included; its MIT license notice is preserved in three.module.js.
